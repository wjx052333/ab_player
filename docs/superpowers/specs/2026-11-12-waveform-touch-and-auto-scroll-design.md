# 波形图交互优化：播放自动跟随滚动与触控手势模式切换设计规范

## 1. 概述与优化背景

在真机运行体验中，波形图操作存在两个关键体验断点：
1. **播放时波形未跟随**：音频播放过程中，播放指针逐渐跑出当前屏幕视口，波形没有自动随时间推进滚动，用户无法持续观察当前发音的波峰与停顿。
2. **手势冲突无法平移浏览**：原先单指在波形上拖拽默认被判定为“框选 A-B 区间”，导致用户无法单指拖动波形来前后浏览音频，只能用双指平移，操作门槛高且不自然。

本设计针对以上问题进行系统性重构：引入**居中平滑跟随引擎**，并在 A-B 控制区左侧增加**醒目手势模式切换器**，默认处于“拖动平移”模式，需要时一键切换至“划选 A-B”模式。

---

## 2. 详细设计

### 2.1 播放时波形居中跟随引擎（Auto-Scroll Following）

#### 逻辑规则
1. **居中对齐算法**：
   - 当音频处于播放状态（`isPlaying == true`）且用户未在触控屏幕时，视口自动将当前播放指针居中：
     $$\text{idealScrollOffset} = \text{currentPosition.seconds} \times \text{pixelsPerSecond} - \frac{\text{viewportWidth}}{2}$$
   - 限制边界：
     $$\text{scrollOffset} = \text{clamp}(\text{idealScrollOffset}, 0, \text{maxScroll})$$
2. **用户干预与防打架机制（Touch Interruption & Cooldown）**：
   - 当检测到用户的触摸事件（`onScaleStart`）：立即将 `_isUserInteracting` 置为 `true`，**暂停自动跟随**，将滚动画布控制权完全交还给用户。
   - 当用户松手离开屏幕（`onScaleEnd`）：启动 1.5 秒无操作倒计时；倒计时结束后，如果仍处于播放中，波形平滑重新恢复居中跟随。
   - 当用户在播放条上点击 Seek、快进退 5 秒、或点击波形任意位置 Seek 时：立即解除暂停并重新居中。

### 2.2 A-B 控制区左侧醒目手势切换器（Gesture Mode Switcher）

#### 模式定义
引入枚举 `WaveformGestureMode`：
- `drag`: **拖动浏览模式（默认模式）**
- `select`: **划选区间模式**

#### UI 布局与视觉风格
在下半部左侧 `AbControlBar` 最左侧位置，嵌入一个极为醒目的模式选择分段控件或切换徽章：

```
+-------------------------------------------------------------------------------+
| 左列：A-B 控制区 (左侧新增醒目手势切换)                                        |
|                                                                               |
| [ ✋ 拖动视图 ]  [ 设 A 点 ]   [ 设 B 点 ]   [ ❌ 清除 ]                      |
| [ ✂️ 划选选区 ]                                                               |
|                                                                               |
|                A: 00:12.4 [-0.1s][+0.1s]   B: 00:18.9 [-0.1s][+0.1s]          |
+-------------------------------------------------------------------------------+
```

- **视觉呈现**：
  - 双行/分段胶囊按钮，常驻显示于 A-B 控制区最左侧。
  - **拖动模式**：青绿色背景高亮（`#3AAFA9`，与波形颜色一致），图标显示手掌 `✋ 拖动`。
  - **划选模式**：明黄色背景高亮（`#F4D03F`，与选区颜色一致），图标显示剪刀/选区 `✂️ 划选`。
  - 用户一眼就能看出当前模式并随时一键切换。

#### 触摸手势映射规则
1. **处于「✋ 拖动视图」模式（默认）**：
   - **单指水平拖拽**：直接拖拽平移波形（更新 `_scrollOffset`），如同在画布上自由滑动查看。
   - **单指点击**：Seek 播放指针到点击的时间点。
   - **双指手势**：继续支持双指捏合缩放（Zoom In/Out）。
2. **处于「✂️ 划选选区」模式**：
   - **单指水平拖拽**：在波形上实时拉出半透明 A-B 选区。
   - **单指点击**：Seek 播放指针。
3. **全局把手优先级（Handle Priority）**：
   - **无论在何种模式下**，只要手指按在已存在的 `[A]` 或 `[B]` 把手热区上，均直接进入把手拖动微调流程，不影响整体模式。
