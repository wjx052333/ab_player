# Audacity 风格 Android 音频播放器 (Flutter) 设计规范文档

## 1. 概述与设计目标

本设计旨在基于 Flutter 构建一款运行在 Android 平台的专业音频播放器。其核心定位是为英语听力精听、跟读模仿（Shadowing）及音乐分段研读提供桌面级音频编辑软件（Audacity）质感的体验。

### 核心特性
- **Audacity 经典时间轴与波形显示**：深色工业质感、时间刻度标尺、平滑对称波形。
- **高自由度触控手势**：双指缩放时间轴（Zoom In/Out）、横向滑动平移（Pan）、波形直接拖拽框选区间、两端游标把手精细拖动调整。
- **专业 A-B 复读引擎**：支持按键/手势打点、区间循环、到达 B 点后静音停顿留白（供用户跟读）、指定循环次数、毫秒级步进微调（±0.1s）。
- **高质量变速不变调**：支持 0.5x ~ 2.0x 变速播放，保持人声音调不失真。
- **高性能长音频渲染**：采用 Isolate 后台解码波峰数据，结合视口局部裁剪算法（Viewport Clipping），确保长音频流畅不掉帧、不爆内存。

## 2. 技术选型与整体架构

### 2.1 技术选型
| 模块 | 选型 | 说明 |
| :--- | :--- | :--- |
| UI 框架 | Flutter 3.x+ (Dart 3.x) | 跨平台渲染与流畅手势响应 |
| 音频播放引擎 | `just_audio` | 成熟稳定、支持高精度 Seek、变速不变调、音频流与状态监听 |
| 音频文件选择 | `file_picker` | 兼容 Android SAF (Storage Access Framework) 及系统级存储选择器 |
| 状态管理 | `flutter_riverpod` 或 `ChangeNotifier` | 响应式状态流，解耦播放状态、选区状态与 UI 渲染 |
| 自定义渲染 | Flutter `CustomPainter` | 像素级还原 Audacity 标尺、波形与选区 |

## 3. Audacity 风格波形视口与手势设计

### 3.1 视口与视觉元素（Visual Specs）
- **画布背景**：Audacity 经典暗灰底色（`#242424`），中心水平基准线（`#404040`）。
- **时间标尺（Timeline Ruler）**：
  - 位于波形区顶部，高度 `26dp`，底部分割细线。
  - 主刻度与次级刻度线：根据当前缩放级别自动调整密度（如每秒、每 5 秒或每 100 毫秒一个主刻度，并标明时间文字，如 `00:15.0`）。
- **波形渲染（Waveform）**：
  - 上下对称经典青蓝色（`#3AAFA9` 或 `#4A90E2`），以竖直条带形式渲染波峰振幅（Peak Min/Max）。
- **A-B 选区覆盖层（Selection Overlay）**：
  - 选区内部：半透明高亮遮罩（`rgba(255, 255, 255, 0.15)`）。
  - A/B 边界线：亮黄色（`#F4D03F`）垂线。
  - A/B 把手（Handles）：顶部或底部配备易触控的把手图形标记 `[A]` 和 `[B]`（触控热区至少 36x36dp）。
- **播放头指针（Playhead）**：
  - 鲜明红色（`#E74C3C`）垂直线，带有三角形顶端标记，随播放实时平滑推进。

### 3.2 触控手势逻辑
1. **直接划选（Drag to Select）**：
   - 在波形空白区域按下并水平拖拽，起始位置为 A 点，抬手位置为 B 点（若 $B < A$，系统自动纠正为 $A < B$）。
2. **把手拖动微调（Handle Dragging）**：
   - 当点击命中 A 把手或 B 把手热区时，随手指水平拖拽逐像素/逐毫秒移动边界。
3. **双指缩放（Pinch-to-Zoom）**：
   - 基于手势中心点缩放时间像素密度（`pixelsPerSecond` 从默认的 `20px/s` 支持放大到 `200px/s`）。
4. **单指滑动查看（Pan/Scroll）**：
   - 处于放大状态时，支持左右拖动波形查看任意时段。
5. **单击跳转（Tap to Seek）**：
   - 单击波形任意位置，立即 Seek 播放指针到对应时间点。

## 4. A-B 复读引擎与精听控制

### 4.1 A-B 状态机与工作流

```
                [ 点击设为A ]
[正常播放] ─────────────────► [A点已定, 待定B]
    ▲                             │
    │ [清除A-B]                   │ [ 点击设为B / 选区完成 ]
    │                             ▼
    └───────────────────── [A-B 复读循环中]
                                  │
                   播放进度到达 B ┘
                          │
                   ┌──────┴──────┐
                   │ 是否达循环上限?
                   ├─────────────┴─────────────┐
                [是]                          [否]
                 │                             │
             暂停播放 / 结束复读         静音等待指定秒数 (0~5s)
                                               │
                                         Seek 到 A 点继续播放
                                         剩余次数 - 1
```

### 4.2 控制参数规格
- **打点设置**：
  - 支持手动按钮【标定 A 点】、【标定 B 点】、【清除选区】。
  - 支持快捷步进微调按键：A 点 `[-0.1s]` / `[+0.1s]`，B 点 `[-0.1s]` / `[+0.1s]`。
- **循环停顿间隔（Loop Interval）**：
  - 可选项：`0s (无缝)`、`1s`、`2s`、`3s`、`5s`。
  - 当到达 B 点时，播放器立即静音，开启倒计时，时间归零后 Seek 回 A 点并恢复音量播放，用于口语跟读模拟。
- **循环次数控制（Loop Count）**：
  - 可选项：`无限循环 (∞)`、`3次`、`5次`、`10次`。
  - 剩余次数归零后，自动暂停播放。
- **变速不变调（Playback Speed）**：
  - 挡位支持：`0.5x`、`0.75x`、`0.9x`、`1.0x`、`1.25x`、`1.5x`、`2.0x`。

## 5. UI 界面布局规格

界面采用暗黑工作台主题（Dark Theme），垂直方向划分为 5 个区域：

1. **顶部信息栏（Top Bar）**：
   - 【打开音频文件】按钮（调用系统文件选择）。
   - 音频标题与总时长显示（如 `Lesson_01.mp3 [03:45.0]`）。
2. **Audacity 波形与标尺主视口（Waveform Viewport）**：
   - 占据屏幕高度约 30%~35%，固定深灰色背景。
   - 顶部标尺、中间波峰、A-B 选区遮罩、红色播放指针。
   - 悬浮缩放控制按钮：【+】、【-】、【适配重置】。
3. **A-B 复读主控与微调栏（A-B Action Bar）**：
   - 【标定 A 点】、【标定 B 点】、【清除复读】三按钮并列。
   - A、B 两个时间点的实时精确数值展示面板（带 ±0.1s 按钮）。
4. **精听辅助参数栏（Tuning Bar）**：
   - 水平横向滚动的 ChoiceChip 组：
     - 倍速选择（Speed）
     - 跟读停顿（Pause Interval）
     - 循环次数（Loop Times）
5. **底部主控栏（Bottom Player Controller）**：
   - 全局进度滑块（Slider）与当前/总时间进度。
   - 控制按键行：【⏪ 后退5s】、【▶ / ⏸ 播放/暂停】、【⏩ 快进5s】。

## 6. 性能优化与边界保护

1. **视口裁剪渲染（Viewport Clipping）**：
   - `WaveformPainter` 只根据当前滚动偏移量和视口宽度计算出可见时间范围 $[T_{start}, T_{end}]$，仅绘制该范围内的波峰柱状图，即使 2 小时的超长音频也能稳定维持 60fps。
2. **后台 Isolate 波峰解析**：
   - 音频导入后，在后台 Isolate 中进行 PCM 采样点抽稀提取（固定每秒保留 50~100 个最大振幅点），主线程显示轻量加载指示，不卡顿 UI。
3. **非法打点与边界保护**：
   - A 点与 B 点强制满足 $T_A < T_B$；若用户反向操作，系统自动交换。
   - 强制最小选区间隔不得低于 `200ms`（0.2s），防止两点重叠导致高频抖动。
   - 在 A-B 激活状态下，用户手动跳转到选区外时，播放器顺畅播放；一旦播放至 B 点，重新触发 A-B 循环与停顿逻辑。
4. **Android 权限与生命周期适配**：
   - 支持 Android 13+ 的 `READ_MEDIA_AUDIO` 权限与旧版本的 `READ_EXTERNAL_STORAGE` 自动兼容。
   - 接入音频焦点监听，处理来电或切换后台时的自动暂停。
