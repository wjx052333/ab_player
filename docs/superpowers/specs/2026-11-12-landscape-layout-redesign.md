# Audacity 风格 Android 音频播放器 - 默认横屏与双列布局重构规范

## 1. 概述与改进背景

在真机实际运行测试中发现：
1. 竖屏模式下垂直高度被标题栏、波形区、A-B 控制区、微调栏与播放栏瓜分，导致部分设备出现像素溢出（Pixel Overflow），且波形区域纵向和横向可视空间局促。
2. 专业音频处理（如 Audacity）的核心体验高度依赖横向时间轴视野。将应用默认置于横屏（Landscape）模式，能够最大化波形展现长度，同时将下方功能面板重构为左右并列排布，彻底消除溢出并大幅提升操作效率。

---

## 2. 屏幕方向策略与配置

### 2.1 Android 原生配置
在 `android/app/src/main/AndroidManifest.xml` 的 `MainActivity` 节点中增加：
```xml
android:screenOrientation="sensorLandscape"
```
确保应用在启动冷启动瞬间即为横屏，避免出现转屏抖动。

### 2.2 Flutter 层朝向锁定与沉浸式显示
在 `lib/main.dart` 启动阶段，通过 `SystemChrome` 锁定朝向：
```dart
await SystemChrome.setPreferredOrientations([
  DeviceOrientation.landscapeLeft,
  DeviceOrientation.landscapeRight,
]);
```
并在外层配置 `SafeArea`，防止异形屏（打孔屏、刘海屏或横向手势指示条）遮挡控制热区。

## 3. 横屏界面布局规格（方案 A）

整体布局按照**上下分层 + 底部左右双列**结构排布：

```
+-----------------------------------------------------------------------------------------------+
| [📂 打开] Lesson_01_Conversation.mp3                                    00:14.2 / 03:45.0     |
+-----------------------------------------------------------------------------------------------+
| 0:00        0:05        0:10        0:15        0:20        0:25        0:30        0:35      |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
|               [======= A-B 选区 (半透明高亮) =======]                                         |
|   ||||||||||| |   |||||||||||||   |   ||||||||||||| |   ||||||||||||||| (Audacity 波形全宽)   |
|               [A]                 ^当前指针         [B]                                       |
|                                                                             [➕ 放大] [➖ 缩小]|
+---------------------------------------------------------------+-------------------------------+
| 左列：A-B 控制与微调 (占宽 ~45%)                              | 右列：精听参数与播放主控 (占宽 ~55%)   |
|                                                               |                               |
| [ 标定 A 点 ]   [ 标定 B 点 ]   [ ❌ 清除 ]                    | 倍速: [0.8x][1.0x][1.2x] 停顿: [1s][2s]|
|                                                               | 循环: [∞][3次]                |
| A 点: 00:12.4  [-0.1s] [+0.1s]                                | 00:14.2 ━━━━●━━━━━━━━ 03:45.0         |
| B 点: 00:18.9  [-0.1s] [+0.1s]                                |     [⏪ -5s]  [ ▶ / ⏸ ]  [⏩ +5s]      |
+---------------------------------------------------------------+-------------------------------+
```

### 3.1 顶部轻量信息栏（Compact Top Bar）
- 紧凑高度（约 36~40dp），包含：
  - 【打开音频文件】快捷图标与文件名
  - 当前播放进度与总时长文本（如 `00:14.2 / 03:45.0`）

### 3.2 上半部：全宽波形视口区（Full-width Waveform Viewport）
- 占据整体高度约 55%~60%，独占屏幕整宽。
- 保留 Audacity 经典深灰底色、时间标尺、对称波形、A/B 双把手、红色播放指针。
- 继承双指缩放、单指平移、选区划选与右下角快捷微型缩放按键。

### 3.3 下半部左列：A-B 复读与微调面板（A-B Control Column）
- 宽度约占屏幕 44%~48%。
- 上行：【设为 A 点】、【设为 B 点】、【清除】三颗操作按钮，采用紧凑按钮样式。
- 下行：A 点与 B 点实时时间数值，两边配备轻触 `[-0.1s]` 与 `[+0.1s]` 微调按钮。

### 3.4 下半部右列：精听参数与主播放面板（Playback & Study Column）
- 宽度约占屏幕 52%~56%。
- 上行：倍速（Speed）、跟读停顿（Pause Interval）、循环次数（Loop Times）的紧凑横滑 ChoiceChip。
- 下行：精简高度的进度条 Slider，下方居中放置【⏪ -5s】、【▶ / ⏸ 播放暂停】、【⏩ +5s】。

## 4. 防溢出与响应式策略（Anti-Overflow Measures）

1. **弹性伸缩容器**：
   - 使用 `Flexible` / `Expanded` 配合权重管理上下比例，避免使用写死的固定高宽。
   - 下方左右双列在极小屏幕时支持局部 `SingleChildScrollView`，从根本上防止 `RenderFlex overflowed by xxx pixels`。
2. **紧凑尺寸规范（Compact Styling）**：
   - ChoiceChip 的 `visualDensity` 设为 `VisualDensity.compact`，内边距压缩为 2~4dp。
   - 按钮内边距与字体适配横屏小高度设计。
